# QQQ Leveraged Short Overlay Backtest

This is research tooling, not investment advice.

## Rules

- Input signal comes from `walkforward_allocation_signal.csv` generated by the macro ML regime analysis.
- Normal / neutral keeps the model DCA allocation near 70%; jump-in uses 100%.
- Risk-off starts with the model allocation near 25%, then uses a drawdown ladder: 40% long below -15%, 60% below -25%, 80% below -35% 252-day drawdown.
- Hedge is removed early when jump-in probability is at least 70%, risk-off probability is below 45%, and latent sentiment is improving.
- Conservative short overlays use a 10% account hedge budget leveraged 3x/5x/10x, so short exposure is about 30%/50%/100% of account equity.
- Aggressive reserve overlays short the idle reserve at 3x/5x/10x. These are included to show tail risk, not as a recommended default.
- Trading cost: `3.0` bps per exposure change; margin borrow: `5.5%`; short borrow: `2.0%`.

## Interpretation

- If a short overlay reduces drawdown but also materially reduces XIRR, it is acting as insurance, not alpha.
- A 10x short overlay can work mathematically only if tightly budgeted; shorting the whole reserve at 10x can be account-ending in fast rebounds.
- This model uses daily-rebalanced exposure math, not broker-specific margin calls, locate availability, tax effects, or intraday liquidation.
